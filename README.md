# Java Library Management System

A console-based library management application demonstrating Java Collections and OOP.

## Features
- Add new books to library
- Borrow and return books
- Search books by title/author
- Track book availability
- Member-based borrowing system

## Java Concepts
- HashMap for efficient book lookup
- ArrayList for managing borrowed books
- Stream API for search and filtering
- Object-Oriented Design

## How to Run
```bash
javac *.java
java Main
